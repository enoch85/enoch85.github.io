# Daniel Hansson - CV Website

## Tech Stack

- Next.js 16.4.0
- React 19.3.0
- TypeScript 6.0.3
- Tailwind CSS 4.3.3
- ESLint 9.39.5
- Node.js 26.x
- GitHub Pages
- CV generator: Python 3.14.8, python-docx 1.2.0, deep-translator 1.11.4


## Automatic updates

Dependabot keeps dependencies updated. Minor and patch updates merge after checks
pass, and the site redeploys with the next daily build. Major updates require
manual review.
